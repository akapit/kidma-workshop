# kidma: סקילים מסדנת "צוות AI לעסק"

שני תוספים ל-Claude. הראשי, `kidma`, עם 11 סקילים:

| סקיל | מה הוא עושה |
|---|---|
| `office-rules` | מראיין אתכם על העסק, שאלה אחת בכל פעם, וכותב את `CLAUDE.md` (חוקי המשרד), עד עמוד אחד. לא דורס קובץ קיים |
| `build-office` | מראיין אתכם על איך העסק עובד ומה אוכל לכם את הזמן (בצ'אט, או בטופס שנפתח בדפדפן), מציע צוות (מנהל, ועובדים כמה שתבחרו), ואחרי אישור בונה אותו: תיק, יומן וזיכרון לכל עובד, צ'אט צוות, טבלת צוות בחוקי המשרד, וסדר תיקיות. עובדים שכבר בניתם משודרגים, לא משוכפלים. אחר כך: "תגייס עובד ל..." מוסיף עובד אחד, ו"תעדכן את הלוח" מרענן דף שמראה את העובדים והמשימות שלהם |
| `copywriting` | כותב טקסט שיווקי בגובה העיניים: פוסט, מייל, סטטוס, מודעה, כותרת. הסקילים האחרים כותבים לפיו |
| `landing-page` | מראיין אתכם, בונה דף נחיתה קצר בעברית (עמודה אחת, נראה טוב בטלפון), ומעלה אותו לאוויר דרך GitHub ו-Vercel (או Netlify) |
| `sales-page` | דף מכירה ארוך להצעה עם מחיר: קודם כל הטקסט ואישור שלכם, ואז בנייה והעלאה |
| `landing-design` | שכבת העיצוב של הדף: כמה שאלות על המותג, בחירת פלטת צבעים, סדר חלקים, וטופס עם הסכמה לפי חוק הגנת הפרטיות. דף נחיתה ודף מכירה משתמשים בו |
| `page-review` | קורא את הדף כמו לקוח, ומחזיר רשימה: השורה, למה היא מפריעה, ומה לכתוב במקומה |
| `creative-board` | כל החומרים של השקה על דף אחד: מודעות, סטטוסים, פוסטים, קרוסלות, סטוריבורד לסרטון ומיילים, עם לוח זמנים |
| `meta-campaign` | מציע 3 זוויות למודעה, ובונה קמפיין בחשבון המודעות שלכם דרך החיבור הרשמי של מטא. הקמפיין נוצר מושהה, ואת ההפעלה עושים אתם |
| `mastermind` | שולחן עגול מדומיין: אנשי שיווק ומכירות מוכרים מתווכחים על השאלה שלכם, ובסוף 3 פעולות לשבוע. מבוסס על הרעיונות שפרסמו, לא ציטוטים שלהם |
| `wrap` | בסוף שיחה: מציע מה לשמור, אתם בוחרים, והתיקייה מגובה ל-GitHub |

## תוסף הווידאו (לא חובה)

`kidma-video` נפרד, למי שעושה סרטונים:

| סקיל | מה הוא עושה |
|---|---|
| `video-subtitles` | מתמלל סרטון (ElevenLabs), מחלק לשורות קצרות, ושורף כתוביות נקיות בעברית או באנגלית, עם קובץ srt |
| `motion-doctrine`, `cut-the-curve`, `seam-craft`, `captions-overlay`, `oversized-cursor` | כללי תנועה, מעברים, כתוביות וסמן עכבר לסרטונים שבונים ב-HyperFrames |

מתקינים עם `/plugin install kidma-video@kidma-workshop`.
הכתוביות צריכות `ffmpeg`, Google Chrome וחשבון ElevenLabs. סט ה-HyperFrames צריך את HyperFrames של HeyGen: `npx skills add heygen-com/hyperframes`.
חמשת סקילי ה-HyperFrames מבוססים על העבודה של HeyGen, ברישיון Apache 2.0 (ראו `plugins/kidma-video/LICENSE` ו-`NOTICE`).

## התקנה

בלשונית Code באפליקציה של Claude, בתוך תיקיית העבודה שלכם, כותבים:

```
/plugin marketplace add akapit/kidma-workshop
```

ואחר כך:

```
/plugin install kidma@kidma-workshop
```

פותחים שיחה חדשה, ומקלידים `/` כדי לראות את הסקילים.

## לפני שמתקינים
סקיל הוא הוראות ש-Claude מקיים. לכן כדאי לבקש ממנו קודם: "תקרא את התוסף הזה ותסביר לי במילים פשוטות מה הוא עושה". זה נכון לכל תוסף, גם לזה.

## עדכונים
כשיש גרסה חדשה: `/plugin marketplace update kidma-workshop`

## לשנות ולהתאים
הסקילים כתובים בעברית פשוטה. כשמשהו לא מתאים לכם, אומרים ל-Claude: "תשמור בחוקי המשרד, תחת העדפות לסקילים, ש...". הסקילים קוראים את `CLAUDE.md` לפני שהם מתחילים, וההעדפות שלכם נשארות גם אחרי עדכון של התוסף (עדכון מחליף את קובצי הסקילים עצמם).
