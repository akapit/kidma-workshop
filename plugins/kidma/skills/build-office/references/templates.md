# התבניות

מעתיקים, ממלאים את מה שבסוגריים המשולשים `<...>`, ומוחקים כל שורת הערה. אף `<...>` לא נשאר בקובץ: או שיש תשובה, או שכתוב "להשלים: <מה חסר>".

**יוצאים מן הכלל:** ההערה בראש `team/board-data.js` (תבנית 16) נשארת כמו שהיא, כולל הסוגריים שבה. ההערות בתבניות הלקוח והפרויקט (13, 14) נשארות, כי הן ההסבר למי שממלא אותן.

**שני סוגים של מקום ריק:**
- `<...>` ממלאים עכשיו, בזמן הבנייה
- `YYYY-MM-DD HH:MM`, `YYYY-MM` ו"שם העובד" הם פורמט שהעובדים ממלאים בכל פעם שהם כותבים. נשארים בקובץ כמו שהם

**לשון:** התבנית של עובד כתובה בלשון נקבה, של המנהל בלשון זכר. מתאימים כל קובץ למין של השם שנבחר: הכותרות, הפעלים, והמתג ("עכשיו את..." או "עכשיו אתה...").

**אורך:** תיק של עובד חדש עד בערך 60 שורות. תיק של עובד ששודרג יכול להיות ארוך יותר: לא מקצרים על חשבון כלל שהיה לו.

- `<slug>`: שם התיקייה באנגלית, אותיות קטנות (`dana`, `writer`)
- `<שם>`: השם בעברית (דנה)
- `<מנהל>` / `<m>`: השם והתיקייה של המנהל
- `<בעל העסק>`: השם הפרטי של המשתמש, אם ידוע. אחרת "בעל העסק"
- `<תאריך>`: התאריך של היום, `YYYY-MM-DD`

כלל הבטיחות, **באותן מילים** בכל תיק:
> שום דבר לא יוצא בלי אישור של <בעל העסק> בזמן אמת: לא שולחים, לא מפרסמים, לא מוחקים, לא משלמים. מכינים טיוטה ומחכים.

ובחוקי המשרד, שבהם בעל העסק מדבר, אותו כלל בגוף ראשון: "שום דבר לא יוצא בלי אישור שלי בזמן אמת: ..." (פעם אחת בלבד בקובץ).

## 10. הבלוק לחוקי המשרד: `CLAUDE.md`
מוסיפים בסוף הקובץ (או מעדכנים טבלת צוות קיימת). לא נוגעים בשאר. כלל הבטיחות נכנס רק אם עוד אין בקובץ כלל שאומר אותו דבר.

```markdown
## הצוות
בתחילת כל שיחה אתה **<מנהל>**, המנהל של המשרד. לפני התשובה הראשונה קרא שלושה קבצים: `team/<m>/<m>.md`, `team/<m>/state.md`, `team/handoffs.md`. כל הנתיבים בקבצי הצוות מתחילים מהתיקייה שבה נמצא הקובץ הזה, גם כשהשיחה נפתחה בתת-תיקייה.

| עובד | מה עושה | איך קוראים לו |
|---|---|---|
| <מנהל>, המנהל | מקבל ממני משימה, מחלק, בודק ומגיש | פשוט כותבים, או `/<m>` |
| <שם>, <תפקיד> | <במשפט> | `/<slug>` |

<!-- סקיל שבניתם ולא שייך לאף עובד, או בן אדם בעסק: שורה אחת כאן, למשל "תפריטים: הסקיל menu-builder, המנהל מפעיל אותו ישירות" -->

## איך הצוות עובד
- לכל עובד תיקייה ב-`team/`: התיק שלו (מי הוא ואיך עובד), יומן עבודה (`state.md`) וזיכרון (`memory.md`)
- התוכנית ל-30 הימים הבאים: `team/next-30-days.md`
- משימה עוברת בין עובדים בצ'אט הצוות, `team/handoffs.md`
- בסוף כל משימה: שורה בזיכרון של העובד ושורה ביומן המשרד, `team/journal.md`
- לקחים נכנסים רק אחרי שאישרתי: לתיק של העובד, או ל-`team/lessons.md` אם הם לכולם
- עובד טעה? מתקנים את התיק שלו, לא רק את התוצאה
- עובד חדש: אומרים למנהל "תגייס עובד ל...". הוא מציע, ומגייס רק אחרי שאישרתי
- הלוח של המשרד: `team/board.html` (לחיצה כפולה). "תעדכן את הלוח" מרענן אותו
- שום דבר לא יוצא בלי אישור שלי בזמן אמת: לא שולחים, לא מפרסמים, לא מוחקים, לא משלמים. מכינים טיוטה ומחכים.
```

**"איפה מה"** (שינוי (ג) בסעיף 4 של `SKILL.md`). אין כותרת כזאת? מוסיפים לפני "הצוות". יש? מוסיפים רק את השורות שחסרות, עם השמות האמיתיים של התיקיות שלהם. שורה או הערה שמסבירה איך להוסיף עובד בדרך הישנה (`team/role-template.md`, "תיקייה ב-.claude/skills"), בכל מקום בקובץ: מוחקים אותה, כי השורה "עובד חדש" כבר בבלוק הצוות. ככה היא לא כתובה פעמיים.

```markdown
## איפה מה
- `business/` המוח של העסק: מי אנחנו, מחירון, סגנון, שאלות נפוצות
- `customers/` קובץ לכל לקוח (מתחילים מ-`_template.md`)
- `projects/` תיקייה לכל פרויקט (מתחילים מ-`_template.md`)
- `team/` הצוות: תיקייה לכל עובד, צ'אט הצוות, יומן המשרד, לקחים, התוכנית, מה מחובר (`tools.md`) והלוח
- <`quotes/`, `social/`, `research/`: רק התיקיות שקיימות> מה שהעובדים מייצרים
```

**אין `CLAUDE.md` בכלל?** יוצרים קובץ קצר: `# <שם העסק>`, `## מי אנחנו` (משאלה 1), `## איך מדברים` (משאלה 10 אם נענתה, אחרת "להשלים"), `## מה אסור` (משאלה 7), `## העדפות לסקילים` (ריק), ואחריהם "איפה מה" והבלוק למעלה. בסוף מציעים: "כדאי להריץ גם את office-rules, כדי שהקובץ יכיר את העסק לעומק".

## 16. הלוח: `team/board-data.js`
הלוח עצמו (`team/board.html`) מועתק מ-`assets/board.html` ולא נערך. הקובץ הזה הוא הנתונים שהלוח מציג, וכותבים אותו מחדש בכל עדכון: **ההערה כמו שהיא, ואחריה הנתונים**. ההערה נשארת בקובץ כדי שהמנהל ידע לעדכן גם בלי הסקיל.

```js
/*
  הלוח של המשרד: הנתונים. את board.html לא עורכים, רק את הקובץ הזה.
  "תעדכן את הלוח" = כותבים את כל הקובץ מחדש: ההערה הזאת כמו שהיא, ואחריה שורת הנתונים (מתחילה ב-window.OFFICE_BOARD, נגמרת ב-;)

  מה קוראים:
  - CLAUDE.md: טבלת הצוות (מי בצוות, המנהל ראשון)
  - לכל עובד: team/<התיקייה שלו>/state.md, ו-memory.md (השורות האחרונות)
  - team/handoffs.md: שורות (מחכה לאישור) ו-(פתוח)
  - team/next-30-days.md: מה שעוד לא סומן

  איך כותבים:
  - JSON תקין בתוך הסוגריים המסולסלים: מפתחות ומחרוזות במירכאות כפולות, בלי פסיק אחרי הפריט האחרון
  - בתוך טקסט: גרשיים עבריים ״ וגרש ׳ (מע״מ, צ׳אט), אף פעם לא " או '
  - עברית פשוטה וקצרה, עד 90 תווים לשורה. בלי שמות תיקיות, בלי פקודות עם /, בלי נתיבים
  - לקוח: שם פרטי בלבד. בלי טלפון, מייל, סכום או פרט אישי

  השדות:
  updated   עכשיו: "YYYY-MM-DD HH:MM"
  business  שם העסק. אין? הכותרת הראשונה של CLAUDE.md. גם אין? ""
  owner     השם הפרטי של בעל העסק
  team      כל עובד בטבלת הצוות, המנהל ראשון. בלי אנשים אמיתיים מהעסק (הם לא עובדים בלוח). לכל אחד:
            name, role (התפקיד במילים), manager (true רק למנהל)
            status: "waiting" אם יש לו שורה (מחכה לאישור) בצ'אט הצוות,
                    "busy" אם יש לו משהו תחת "פתוח" ביומן העבודה או שורה (פתוח) אליו בצ'אט,
                    אחרת "free"
            now: הדבר הראשון שפתוח אצלו, במשפט. "" אם פנוי
            open: עד 3 דברים פתוחים, כל אחד במשפט
            last: השורה האחרונה בזיכרון שלו, { "date": "YYYY-MM-DD", "text": "..." }
            week: כמה שורות בזיכרון שלו מ-7 הימים האחרונים, בלי שורת ההצטרפות
  waiting   כל שורה (מחכה לאישור) בצ'אט הצוות: { "who": שם העובד, "what": מה מחכה, "since": "YYYY-MM-DD" }
  recent    עד 8 השורות האחרונות מכל הזיכרונות יחד, החדשה ראשונה: { "when": "YYYY-MM-DD HH:MM", "who", "text" }
  next      עד 4 פריטים שלא סומנו בתוכנית 30 הימים, לפי הסדר, כל אחד במשפט
*/
window.OFFICE_BOARD = {
  "updated": "<YYYY-MM-DD HH:MM>",
  "business": "<שם העסק>",
  "owner": "<בעל העסק>",
  "team": [
    { "name": "<מנהל>", "role": "המנהל", "manager": true, "status": "busy",
      "now": "<המשימה הראשונה משאלה 11>", "open": ["<המשימה הראשונה>"],
      "last": { "date": "<תאריך>", "text": "הצטרף לצוות" }, "week": 0 },
    { "name": "<שם>", "role": "<התפקיד>", "manager": false, "status": "free",
      "now": "", "open": [],
      "last": { "date": "<תאריך>", "text": "הצטרפה לצוות" }, "week": 0 }
  ],
  "waiting": [],
  "recent": [
    { "when": "<תאריך> <שעה>", "who": "<שם>", "text": "הצטרפה לצוות" }
  ],
  "next": ["<הפריט הראשון בתוכנית 30 הימים>"]
};
```
